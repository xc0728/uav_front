# 冲突检测前端接入说明

更新日期：2026-11-05。当前前端采用后端目录驱动，不在页面维护固定的要素分类白名单。

## 使用流程

1. 在“路径冲突检测（所有冲突）”“路径冲突检测（首个冲突）”或医疗场景演示中选择活动 L17 真高数据集。
2. 页面调用 `POST /api/airRoute/conflictCheck/catalog`，按后端分组列出基础状态、模型来源、航图数据集、数值环境属性和正式维护强制约束。
3. 勾选要素，选择目录声明的方式并填写参数。只有后端声明的方法、字段和选项才显示控件。
4. 所有/首个模式分别提交 `mode=ALL/FIRST`，仍调用 `POST /api/airRoute/conflictCheck/clickhouse`，但使用 rules 数组。

规则携带 `elementId/elementRevision/method`，目录未加载成功不允许提交，不自动回退旧开关模式。
未选中的可选要素不检测；正式维护强制约束显示为只读勾选，后端始终检查。

## 判定能力

- 基础状态：数据覆盖、禁飞、限制/管制、明确不可飞、已挂载模型占用分别选择；地形可检查地表/地下或配置最低离地高度。
- 全部模型来源按模型占用判障，包含建筑、实景三维、通信、导航、监视、输电及新来源；没有 L17 投影的来源显示不可用原因。
- 三维航图支持碰撞；二维背景要素支持水平避让，并可限定适用离地高度。二维水平避让不是物理三维碰撞。
- 航图数值属性可配置允许范围；分类字段可配置“避开指定属性取值”。分类取值输入 JSON 数组，带前导零的代码使用字符串。
- 数值环境属性来自当前数据集的活动绑定，可配置允许范围及缺测策略。参数没有默认业务阈值。
- 时变属性要求 UTC Unix 秒级 timestamp，整条航迹使用同一时刻；没有逐格到达时间或飞行器动态占用判定。
- 距离缓冲尚未实现，目录没有提供此方式。

## 刷新与结果

同一数据集刷新时保留原规则；要素下线或版本变化后明确提示，旧规则不能静默继续执行。
失效的已选规则保留可移除入口。切换数据集或状态版本会清空旧规则并提示重新选择。

结果显示已执行的可选规则、要素版本、实际值、允许范围、适用离地高度、分类避让取值和关联对象。
API 错误、超时与缺测不能显示为已确认安全；地图按完整三维编码匹配，FIRST 命中后其余格元保持灰色。

场景 A* 使用选中数据集的 L17 ClickHouse 规划入口，只转换 A* 已支持的候选条件；规划成功后必须执行完整目录规则复检。
尚未支持在 A* 搜索中直接优化所有属性阈值，复检仍可能拒绝候选路线。

## 配色与选点

组件使用现有 --panel-* 主题变量，适配白色、科技蓝、绿色侧栏；场景演示保留深色变量。
三个航迹输入分支分别写入各自列表，A* 禁飞区绘制保留。输入航迹时模型/网格点击优先添加航点，
非输入模式保留属性查看；深度拾取不可用时回退地形射线和椭球。
